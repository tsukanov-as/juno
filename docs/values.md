# Значения, даты и форматирование

Документ описывает преобразования значений, арифметику, даты и строки juno.
Различия с 1С 8.3.27.1606 и OneScript 2.2.1 указаны для соответствующих функций.
Рабочий пример: `juno run examples/значения/Программа.bsl`.

## Преобразования и даты

`Строка(Число)` сохраняет десятичную точку и не добавляет группировку; числовой контракт
`BigDecimal` сохраняет точные сложение и умножение. Деление, как в проверенной 1С,
сохраняет 27 знаков после запятой либо 27 значащих знаков для результата меньше 1. `Число` поддерживает преобразование
десятичных строк, включая запятую. `Строка(Дата)` возвращает `дд.ММ.гггг ЧЧ:мм:сс`,
включая `01.01.0001 00:00:00` для пустой даты. Для сохранения долей секунды используйте XML API.

`Дата` принимает одну компактную строку из 8, 12 или 14 цифр: `ггггММдд[ЧЧмм[сс]]`,
либо ровно 3 или 6 чисел: год, месяц, день и при необходимости час, минута, секунда.
Нулевые строки соответствующей длины обозначают пустую дату. Диапазон — 0001–9999;
невозможные календарные даты и выход за диапазон при арифметике отвергаются.
Произвольный текст, локализованное представление и ISO-строка не принимаются `Дата(Строка)`.
Литералы в апострофах дополнительно допускают разделители: пробел, `.`, `:`, `/`, `-`.

Все функции таблицы имеют ровно указанное число обязательных аргументов; пропуски
и лишние аргументы дают ошибку. RU/EN-имена регистронезависимы.

| Функция | English | Аргументы и результат |
| --- | --- | --- |
| `Год`, `Месяц`, `День`, `Час`, `Минута`, `Секунда` | `Year`, `Month`, `Day`, `Hour`, `Minute`, `Second` | дата → число |
| `НачалоДня`, `КонецДня` | `BegOfDay`, `EndOfDay` | дата → 00:00:00 / 23:59:59 |
| `НачалоМесяца`, `КонецМесяца` | `BegOfMonth`, `EndOfMonth` | дата → первый/последний день месяца с теми же границами времени |
| `ДобавитьМесяц` | `AddMonth` | дата, число месяцев → дата |
| `ТекущаяДата` | `CurrentDate` | без аргументов → дата в системном часовом поясе |
| `ТекущаяУниверсальнаяДата` | `CurrentUniversalDate` | без аргументов → дата UTC |
| `Булево` | `Boolean` | примитив → булево |
| `ЗначениеЗаполнено` | `ValueIsFilled` | значение → булево |
| `XMLСтрока` | `XMLString` | примитив → строка |
| `XMLЗначение` | `XMLValue` | тип, лексическая строка → примитив |
| `Формат` | `Format` | значение, форматная строка → строка |

Части/границы даты и `ДобавитьМесяц` принимают также компактную строку даты.
`ДобавитьМесяц` обрезает дробную часть числа месяцев к нулю, сохраняет время и доли секунды;
если в новом месяце нет такого дня, выбирается его последний день.
Границы дня/месяца отбрасывают доли секунды. Текущие даты возвращаются с точностью до секунды.

`Булево` принимает булево, число (0 — ложь, остальные — истина) и строки
`Истина`/`Да`/`True`, `Ложь`/`Нет`/`False` без учёта регистра. Пробелы не обрезаются;
строки `"1"`, `"0"` и пустая строка отвергаются.

`ЗначениеЗаполнено` возвращает ложь для `Неопределено`, `Null`, нуля, пустой/пробельной
строки (включая NBSP), даты 0001-01-01 00:00:00, пустых поддерживаемых коллекций
и двоичных данных нулевой длины. Булево `Ложь` считается заполненным.

## Формат

Поддерживаются параметры таблицы и `Л/L` (локаль, например `ru_RU`, `en_US`, `de_DE`).
Неизвестные параметры игнорируются, как в проверенной 1С.
Известные параметры другого типа значения игнорируются, как в проверенных вызовах OneScript.
Пустая строка параметров задаёт русское представление. Строки возвращаются без изменений,
`Неопределено` и `Null` — как пустая строка.

| Параметр | English | Значение |
| --- | --- | --- |
| `ЧДЦ` | `NFD` | число знаков после запятой, 0–1000; округление половин от нуля |
| `ЧРД` | `NDS` | разделитель дробной части; по умолчанию запятая |
| `ЧРГ` | `NGS` | разделитель групп; по умолчанию NBSP U+00A0 |
| `ЧГ` | `NG` | размеры групп, описаны ниже; по умолчанию `3,0` |
| `ЧН` | `NZ` | представление нуля |
| `ЧЦ` | `NL` | общее число цифр; при переполнении — максимальное представимое значение |
| `ЧВН` | `LZ` | дополнять целую часть нулями до ЧЦ (флаг) |
| `ЧС` | `NS` | десятичный сдвиг, положительное число делит на 10 в этой степени |
| `ЧО` | `NN` | отрицательное число: 0 — скобки, 1 — минус, 2 — минус с пробелом, 3/4 — минус в конце |
| `ЧФ` | `NF` | шаблон числа, `Ч`/`N` подставляет готовое представление |
| `ДЛФ` | `DLF` | локальное представление: Д, ДД, В, ДВ, ДДВ |
| `ДП` | `DE` | представление пустой даты |
| `ДФ` | `DF` | шаблон даты |
| `БЛ`, `БИ` | `BF`, `BT` | представления ложь/истина; по умолчанию `Нет`/`Да` |

`ЧГ=0` отключает группировку; `ЧГ=n` выделяет только последнюю группу из n цифр;
`ЧГ=n,0` повторяет n; `ЧГ=n,m` и `ЧГ=n,m,0` выделяют последнюю группу n,
затем повторяют m. Все размеры — целые 0–1000. Третье положительное число не поддерживается
и отвергается. Знак числа не входит в группу. Без `ЧДЦ` незначащие конечные нули отбрасываются.
Нулевое значение представляется пустой строкой либо значением `ЧН`. Ненулевое
число, округлённое до нуля при `ЧДЦ=2`, представляется как `0,00`. Числовые операции остаются точными,
ограничение форматирования не ограничивает числа в языке.

Параметры разделяются `;`. Некавыченный параметр с внутренним пробелом игнорируется, как в 1С. Для пробелов, `;` и шаблонов времени
заключайте всё значение в одинарные или двойные кавычки. Кавычка внутри значения
удваивается. Последнее повторение параметра побеждает.

```bsl
Формат(1234.5, "ЧГ=0;ЧРД=.;ЧДЦ=2"); // 1234.50
Формат(1234.5, "ЧГ=3;ЧРГ=';';ЧРД='=';ЧДЦ=2"); // 1;234=50
Формат(Истина, "БИ='yes;ok';БЛ=no"); // yes;ok
Формат(Дата(2024,2,29,13,4,5), "ДФ='yyyy-MM-dd ''at'' HH:mm:ss'");
// 2024-02-29 at 13:04:05
```

В `ДФ` поддерживаются `y`–`yyyy` (`г`–`гггг`), `M`–`MMMM` (`М`–`ММММ`),
`d`–`dddd` (`д`–`дддд`), `H`/`HH` (`Ч`/`ЧЧ`), `h`/`hh` (`ч`/`чч`),
`m`/`mm` (`м`/`мм`), `s`/`ss` (`с`/`сс`), `t`/`tt` (`в`/`вв`, AM/PM),
`f`–`fffffffff` для долей секунды. Имена месяцев и дней недели зависят от `Л`. Русский месяц без дня — «Январь»,
с днём — «5 января».
Текст заключают в кавычки внутри шаблона; `\` экранирует следующий символ.
Неизвестные буквенные символы, незакрытые кавычки и неверные длины токенов дают ошибку.
Пустая дата использует `ДП` (по умолчанию пустая строка).

## Машинные XML-преобразования

Эти функции преобразуют лексическое содержимое примитива, а не XML-документ:
`XMLСтрока("<&>")` возвращает `<&>`, `XMLЗначение(Тип("Строка"), "&lt;")` возвращает `&lt;`.
Экранирование разметки и разрешение сущностей не выполняются.

- Число: десятичная точка, без группировки и экспоненты; незначащие конечные нули отбрасываются. При разборе допустимы знак, `.5`, `5.`, внешние пробелы; запятая,
  экспонента, NaN/Infinity отвергаются. Предела .NET Decimal нет.
- Булево: запись `true`/`false`; чтение также `1`/`0`, с внешними пробелами и с учётом регистра.
- Дата: запись `yyyy-MM-ddTHH:mm:ss` с необходимыми долями секунды до 9 знаков;
  чтение этой формы и `yyyy-MM-dd`. Календарь проверяется строго.
- `Неопределено` и `Null`: запись пустой строки; чтение пустой строки в явно указанный тип.

Даты BSL не содержат часового пояса. Суффиксы `Z`, `+03:00` и другие смещения
в этом поднаборе **отвергаются**, чтобы не терять их значение молча.
OneScript в проверенных вызовах принимал смещение, сохраняя локальные поля;
juno этого поведения не воспроизводит. OneScript также не записывал доли секунды
в `XMLСтрока(Дата)`; juno сохраняет их для точного обратного преобразования.
Человеческий `Формат` и локаль JVM не влияют на XML-представление.

## Строки

`СокрЛ`/`TrimL`, `СокрП`/`TrimR` обрезают пробелы слева/справа,
`СокрЛП`/`TrimAll` — с обеих сторон. Учитывается NBSP.
`ПустаяСтрока` возвращает истину для пустой строки и строки из пробелов.

### Порядок строк

Операторы `<` `>` `<=` `>=`, `Мин`/`Макс` и `СортироватьПоПредставлению` упорядочивают строки так же,
как 1С 8.3.27.1606 (словарный порядок, а не коды символов): строчная буква раньше прописной
(`a < A`), `е < ё < ж`, латиница раньше кириллицы, цифры раньше букв, а пробел, табуляция и знаки —
обычные символы с весом ниже цифр (`"a b" < "ab"`, `"_" < "-" < "." < "0"`). Равенство `=` остаётся точным
(`"a" <> "A"`). Правила для русских и латинских букв, цифр и основных знаков заданы
в `StringOrder` и не зависят от JDK. Для остальных символов порядок задаёт русская таблица JDK.

`СтрСравнить`/`StrCompare` принимает две строки, не различает регистр (приводит к нижнему) и возвращает
-1/0/1 по тому же порядку; `ss` и `ß`, `е` и `ё` остаются разными. OneScript в наблюдённом окружении
давал другие знаки и различал `ss`/`ß`. Порядок не предназначен для протокольной сортировки.

`СтрЗаканчиваетсяНа`/`StrEndsWith` учитывает регистр, пустой суффикс отвергается.
`СтрЧислоСтрок`/`StrLineCount` считает LF: пустая строка содержит одну строку,
завершающий LF добавляет пустую строку. CR не удаляется.
`СтрПолучитьСтроку`/`StrGetLine` принимает строку и номер с 1; дробная часть номера
обрезается к нулю, номер ≤0 возвращает пустую строку, номер больше количества — ошибка.
При CRLF возвращаемая строка сохраняет CR, как в проверенном OneScript.

`СтрЧислоВхождений` считает неперекрывающиеся вхождения (пустая
подстрока — 0), `Найти` возвращает позицию с 1 (пустая подстрока — 1), `ТРег`
приводит слова к начальному верхнему регистру. `НСтр` выбирает язык из строки
вида `ru='Привет';en='Hello'`, по умолчанию ru; отсутствующий язык — пустая строка.
`УниверсальноеВремя` и `МестноеВремя` преобразуют дату через указанный IANA-пояс,
пустое имя — системный пояс; `ЧасовойПояс()` возвращает его идентификатор.
`РежимОкругления.Окр15как10` округляет половины к нулю, `Окр15как20` — от нуля.
`Число(Строка)` отвергает экспоненциальную запись; числовой токен JSON её принимает.
