# Каталог API

[Модули / Modules](modules.md) предоставляет общий экземпляр модуля через `Получить/Get`,
проверку доступности `Содержит/Contains` и список собранных модулей `Имена/Names`.

`juno api --format json` возвращает RU/EN имена и minArguments/maxArguments зарегистрированных
глобальных функций; `juno api` — краткий текстовый список. Каталог содержит функции реестра `GlobalFunctions`,
остальные функции языка описаны ниже. Конструкторы, методы, defaults и ограничения
перечислены ниже и в тематических справочниках. Аргументы в квадратных скобках необязательны;
пропуск слота в BSL задаётся запятой, `Неопределено` принимается только где это описано.

## Проверки и временные данные

`Новый Утверждения` / `New Assertions` не принимает аргументов. Методы:

| RU / EN | Сигнатура |
|---|---|
| Равно / Equal | `(Фактическое, Ожидаемое[, Сообщение=""])`; сравнивает числа без scale, вложенные массивы/структуры/maps, сообщает путь, длину и первую разницу строк (UTF-16) |
| Истина / True, Ложь / False | `(Значение[, Сообщение=""])` |
| Содержит / Contains | `(Текст, Подстрока)` |
| Провал / Fail | `(Сообщение)` → исключение |
| ВызываетИсключение / Throws | `(Объект, ИмяЭкспортногоМетода[, Аргументы=Неопределено, ПодстрокаОшибки=""])`; аргументы — Массив, отсутствие исключения/неверный текст — провал |

Diff ограничен глубиной 100; текст значений в сообщении ограничен 256 символами. Коллекции
сравниваются по содержимому и именам ключей, произвольные BSL-объекты — по identity.

`Новый ВременныйКаталог([Префикс="juno-test-"])` / `New TemporaryDirectory`:
свойство `Путь/Path` — абсолютный путь; `Закрыть/Close()` удаляет каталог рекурсивно без
следования symlink и идемпотентен. Префикс: 3..64 букв/цифр/`_`/`-`.
Контекст теста автоматически закрывает открытые каталоги при успехе/исключении.

```bsl
Процедура ТестРасчёт() Экспорт
    А = Новый Утверждения;
    А.Равно(0.1 + 0.2, 0.3);
    Каталог = Новый ВременныйКаталог;
    ФайлКаталога = Новый Файл(Каталог.Путь);
    А.Истина(ФайлКаталога.ЭтоКаталог());
    Каталог.Закрыть();
КонецПроцедуры
```

Это поддерживаемый вычислительный поднабор, не API всей платформы 1С/OneScript. Запросы, формы,
метаданные, Асинх/Ждать и динамический загрузчик не поддерживаются. Работающие примеры в examples
проверяются java Build.java test; filesystem/JSON/network/process контракты — в тематических docs.
