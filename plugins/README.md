# Плагины

Плагин — это обычный модуль на 1С, который проверяет или изучает код.
Парсер разбирает каждый файл в синтаксическое дерево, обходит его и зовёт плагин
на тех узлах, на которые плагин подписался.

```sh
juno lint src --dialect 1c --plugin МояПроверка.bsl
juno lint src --dialect 1c --plugin МояПроверка.bsl --params params.json
juno lint src --dialect 1c --plugin проверки  # все плагины из папки
```

Плагины и параметры можно записать в `juno.json` в корне проекта — тогда хватит `juno lint src --dialect 1c`:

```json
{
  "plugins": ["проверки"],
  "params": {"МногоПараметров.bsl": {"Максимум": 5}}
}
```

`--dialect 1c` выбирает синтаксис платформы. Для исходников juno этот флаг не нужен:
по умолчанию `lint` проверяет также семантику juno, включая имена типов и модулей.

## Первый плагин

Проверка «у метода не больше трёх параметров»:

```bsl
// МногоПараметров.bsl

Перем ТаблицаОшибок, Максимум;

// Вызывается перед обходом каждого файла.
Процедура Открыть(Парсер, Параметры) Экспорт
    ТаблицаОшибок = Парсер.ТаблицаОшибок();
    Максимум = 3;
    Если Параметры <> Неопределено И Параметры.Свойство("Максимум") Тогда
        Максимум = Параметры.Максимум;
    КонецЕсли;
КонецПроцедуры

// На какие узлы дерева подписан плагин.
Функция Подписки() Экспорт
    Подписки = Новый Массив;
    Подписки.Добавить("ПосетитьОбъявлениеМетода");
    Возврат Подписки;
КонецФункции

// Вызывается для каждой процедуры и функции.
Процедура ПосетитьОбъявлениеМетода(Объявление) Экспорт
    Сигнатура = Объявление.Сигнатура;
    Если Сигнатура.Параметры.Количество() > Максимум Тогда
        Ошибка = ТаблицаОшибок.Добавить();
        Ошибка.Источник = "МногоПараметров";
        Ошибка.Текст = СтрШаблон("У метода %1 больше %2 параметров", Сигнатура.Имя, Максимум);
        Ошибка.НомерСтрокиНачала = Сигнатура.Начало.НомерСтроки;
        Ошибка.НомерКолонкиНачала = Сигнатура.Начало.НомерКолонки;
    КонецЕсли;
КонецПроцедуры

// Вызывается после обхода файла. Что вернёт — то и будет результатом плагина.
Функция Закрыть() Экспорт
    Возврат Неопределено;
КонецФункции
```

```
$ juno lint code.bsl --dialect 1c --plugin МногоПараметров.bsl
code.bsl:4:1: У метода Много больше 3 параметров [МногоПараметров]
Файлов: 1, замечаний: 1, файлов с ошибками: 0
```

## Как это устроено

У плагина три обязательных экспортных метода:

| Метод | Когда вызывается | Зачем |
| --- | --- | --- |
| `Открыть(Парсер, Параметры)` | перед обходом файла | взять у парсера всё нужное, прочитать параметры |
| `Подписки()` | при подключении к парсеру | вернуть массив имён подписок |
| `Закрыть()` | после обхода файла | вернуть результат: строку, массив, структуру или `Неопределено` |

Каждый файл обходит новый экземпляр плагина, поэтому переменные модуля не тянутся
от файла к файлу.

**Подписки.** Имя подписки — `Посетить` или `Покинуть` плюс тип узла:
`ПосетитьОбъявлениеМетода`, `ПокинутьОператорЕсли`, `ПосетитьВыражениеТернарное` и т. д.
`Посетить…` вызывается до обхода вложенных узлов, `Покинуть…` — после.
Полный список — в функции `Подписки()` в [src/Parser.bsl](../src/Parser.bsl).

**Узлы.** Какие у узла поля, описано в комментариях к процедурам `Инициализировать…`
в [src/Parser.bsl](../src/Parser.bsl), там же примеры кода для каждого узла.
У каждого узла есть `Тип`, а также `Начало` и `Конец` — первый и последний токен
со строкой (`НомерСтроки`), колонкой (`НомерКолонки`) и позицией в тексте (`Позиция`, `Длина`).

**Что даёт парсер в `Открыть`:**

| Метод | Что возвращает |
| --- | --- |
| `Типы()` | типы узлов, для сравнения: `Узел.Тип = Типы.ОператорВозврат` |
| `Токены()`, `ТаблицаТокенов()` | все токены файла, в том числе комментарии |
| `Исходник()` | текст файла |
| `ТаблицаОшибок()` | сюда плагин пишет замечания |
| `Стек()` | родительские узлы текущего узла |
| `Счетчики()` | сколько родителей каждого типа, например `Счетчики.ВыражениеТернарное` |
| `Директивы()`, `Аннотации()` | `&НаКлиенте`, `&Перед` и другие |

**Замечание** — строка `ТаблицаОшибок`. Достаточно заполнить `Источник`, `Текст`,
`НомерСтрокиНачала` и `НомерКолонкиНачала`; есть ещё `НомерСтрокиКонца`, `НомерКолонкиКонца`,
`ПозицияНачала` и `ПозицияКонца`.

**Параметры** приходят из JSON-файла `--params` или из `juno.json` структурой. Ключ — имя файла плагина:

```json
{"МногоПараметров.bsl": {"Максимум": 5}}
```

**Что доступно внутри плагина.** Плагин исполняется рантаймом juno: язык 1С
и его библиотека (`Массив`, `Структура`, `Соответствие`, строковые функции и т. д.),
но не объекты платформы вроде запросов или справочников.

## Примеры в этой папке

Подключаются как любые плагины: `--plugin plugins` — все сразу, `--plugin plugins/ЗапросВЦикле.bsl` — один.
Их удобно скопировать в свой проект и переделать под себя.

| Плагин | Что находит | На чём построен |
| --- | --- | --- |
| [ЗапросВЦикле](ЗапросВЦикле.bsl) | запрос к базе выполняется на каждой итерации цикла | `Счетчики()` — внутри цикла ли узел; состояние между узлами — в каких переменных лежит запрос |
| [ПодавлениеИсключений](ПодавлениеИсключений.bsl) | блок `Исключение` глушит ошибку | пара `Посетить…`/`Покинуть…` со своим стеком; параметр `Обработчики` |
| [МодальныеВызовы](МодальныеВызовы.bsl) | `Вопрос`, `Предупреждение` и другие модальные вызовы | список запрещённых методов — самая простая проверка |
