# Проверка совместимости BSL

Для реализации и проверки стандартных API juno, совместимости с 1С/OneScript
и разбора различий поведения используй проектный скилл
[bsl-differential-testing](.agents/skills/bsl-differential-testing/SKILL.md).
В нём есть запуск настоящей платформы 1С в новой временной базе, OneScript,
juno CLI и самостоятельного JAR на общих BSL-кейсах.

Сравнивай доступные релевантные движки и явно отмечай непроверенные режимы.
Расхождения 1С и OneScript требуют выбора контракта; не подменяй наблюдения
предположением и не воспроизводи баги OneScript автоматически.
